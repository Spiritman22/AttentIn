# Attent-in

Android app implementing a four-position gradual light sequence synchronized with the supplied `attent-in.mp3` voice recording.

Sequence: white/forehead → yellow/heart → blue/left shoulder → red/right shoulder → repeat.

## Build
Open the project in Android Studio (Ladybug or newer), allow Gradle sync, then Run on an Android device/emulator. The included voice file is packaged at `app/src/main/res/raw/attent_in_voice.mp3`.
